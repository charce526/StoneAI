# AI 识石 v1.1.0

AI 识石是一款支持自定义 OpenAI 兼容多模态服务的 Android 岩石与矿物识别应用。

## 本次发布

- 支持拍照和相册图片识别
- 照片全流程统一为 1:1 展示比例
- 支持读取并展示照片拍摄时间与地点
- 提供结构化识别结果、本地历史记录和详情页面
- 生成包含照片、拍摄地点和时间的自适应高度分享卡片
- 分享预览与实际分享图片保持一致
- API Key 使用 Android Keystore 加密保存在设备端
- 支持自定义 OpenAI 兼容接口地址与视觉模型

## 安装要求

- Android 8.0（API 26）及以上
- 需要用户自行配置支持图片输入的 OpenAI 兼容服务和 API Key

## 下载说明

正式发布时将附带经过正式证书签名的 APK。请不要分发或安装文件名包含 `_unsigned` 的构建产物。

## 重要提示

AI 识别结果仅供学习和科普参考，不能替代专业地质鉴定、珠宝检测或其他具有法律效力的检测结论。照片会在用户主动识别时发送到其配置的 AI 服务，请在使用前了解相应服务的隐私政策与费用规则。
